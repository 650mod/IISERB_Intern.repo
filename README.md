# Signals and Systems — EdTech Learning Modules

This repository contains the **EdTech learning modules developed during my internship at IISER Bhopal (IISERB)**, focused on the subject **Signals and Systems**.

The modules are designed to present fundamental concepts of Signals and Systems in a structured, interactive, and learner-friendly manner, combining theoretical explanations with examples, visualizations, and problem-solving activities.

## 📚 Topics Covered

The repository includes learning modules covering key concepts from Signals and Systems, such as:

- Classification of Signals
- Continuous-Time and Discrete-Time Signals
- Basic Signal Operations
- System Classification
- Linear Time-Invariant (LTI) Systems
- Convolution
- Impulse Response
- Time and Frequency Domain Representation
- Fourier Series
- Fourier Transform
- Sampling
- Other related concepts in Signals and Systems

> The exact topics and organization may vary across the individual modules.

## 🎯 Objectives

The modules were developed with the following objectives:

- Simplify fundamental Signals and Systems concepts for learners.
- Present mathematical concepts in an intuitive and structured manner.
- Support conceptual understanding through examples and visual representations.
- Create self-contained learning resources suitable for online/EdTech environments.
- Encourage active learning through exercises and assessment components.
